新增探索、系列、标签、音乐馆、近况、友链和片单；保留原有性能优化。
更新后管理员首次打开后台会创建功能页面、整理现有两篇算法文章，并为已有两篇音乐笔记添加信息卡。原文章正文不改写。

停用插件时，仅将本插件创建且仍公开的功能页面设为草稿，保留文章、系列、元数据与设置；重新启用时恢复本插件隐藏的页面。
回退旧版前先停用 1.2.0，再安装 1.0.2。直接覆盖旧版不会自动隐藏新增页面。
字体为原字体子集，未来新字符可能回退系统字体。
Argon vendor bundle is derived from the installed GPL-3.0 theme; original library license comments are retained. WordPress supplies jQuery.
